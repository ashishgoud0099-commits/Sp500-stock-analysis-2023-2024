# S&P 500 Stock Analysis 2023-2024

## Overview
Analysis of 10 S&P 500 stocks (AAPL, AMZN, GOOGL, JNJ, JPM, 
MSFT, NVDA, TSLA, WMT, XOM) across 2023-2024 using Excel, 
Tableau, and Power BI.

## Tools Used
- **Excel** – Data cleaning & summary statistics
- **Tableau** – Interactive dashboard
- **Power BI** – Multi-page report (Market Overview, 
  Performance Analysis, Risk Analysis)

## Key Findings
- **Best Stock:** NVDA (Avg Daily Return: 0.497%)
- **Worst Stock:** JNJ (Avg Daily Return: -0.037%)
- **Best Sector:** Automotive (0.330% avg return)
- **Most Volatile:** TSLA (volatility score: 3.67)
- **54% of trading days** were profitable days

## Dataset
- 5,020 records of daily stock data
- Columns: Date, Symbol, Open, High, Low, Close, Volume, Sector
